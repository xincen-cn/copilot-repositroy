## What model are you?

I am GitHub Copilot, an AI programming assistant developed collaboratively by GitHub and OpenAI. In this repository context, I am running as the **GitHub Copilot Coding Agent**, powered by **Claude Sonnet** (developed by Anthropic) to handle complex coding tasks.
